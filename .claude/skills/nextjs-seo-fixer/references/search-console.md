# Search Console & keyword analysis

Use this when the user uploads a Google Search Console "Performance on Search" export (xlsx or csv; sheets usually: Chart, Queries, Pages, Countries, Devices, Search appearance, Filters) or asks why keywords get no clicks or are not on page 1.

## 1. Read the file properly
- Read every sheet. Note the date filter in the Filters sheet, but ALSO check the first date with impressions in the Chart sheet. A "Last 3 months" export may contain only a few weeks of real data if the site is new. Always tell the user the real data period.
- Totals: clicks, impressions, CTR, average position. Split by device (mobile share matters for local search) and country.
- Clicks by page can be higher than clicks by query: Google hides rare/anonymised queries. Explain this instead of treating it as an error.
- Look at the daily trend. Clicks in the first days after launch are often the owner or staff testing the site. Mention this possibility; do not state it as fact.

## 2. Judge data size before judging performance
- Under ~4 weeks of data or under ~1,000 impressions: say the sample is too small for firm conclusions, and give only the clear issues.
- Small towns have low search volume. 1–10 impressions per keyword per month is normal; do not call that a failure.

## 3. Group the queries
Put every query into one group:
- **Brand**: business name, doctor/owner names, Hindi or other-script spellings (e.g. "सतिंदर"), name + city. Target: position 1. If a brand query is below position 2, it is the top priority — other sites (Justdial, Practo, Lybrate, Facebook, directories) are probably outranking the official site.
- **Local money keywords**: service/specialist + city ("eye specialist muzaffarnagar", "cataract surgery in muzaffarnagar").
- **Near me**: mostly decided by Google Business Profile (map pack), not the website.
- **Service/condition info**: "chalazion", "squint therapy", "treatment for eye bags", Hindi/Hinglish questions.
- **Irrelevant/too broad**: "doctor near me", other specialties. Ignore.

## 4. Find the opportunities
- **Page 1 but no clicks (position 1–10, CTR ~0)**: CTR problem. Causes: map pack and ads above organic on mobile, weak title/description, other sites for brand searches. Fix titles/descriptions and Google Business Profile.
- **Striking distance (position 8–20)**: content/relevance problem. Strengthen the matching page: keyword in title/H1, more real content (procedure, cost factors, recovery, FAQs, doctor), internal links from the homepage and nav.
- **Keyword wording gaps**: if "eye doctor/specialist" ranks well but "eye hospital" ranks badly, the page likely never uses the word "hospital". Suggest adding it only if it is true for the business.
- **Query with no matching page**: suggest a new page or section only if the business really offers that service.
- **Hindi / Hinglish queries**: suggest Hindi or Hinglish FAQ sections on the relevant page.
- **Pages with impressions but position >10**: list them with the fix.

## 5. Keyword-to-page map
Assign each important keyword group to ONE page so pages do not compete:
| Page | Primary keyword | Secondary keywords |
Homepage usually gets brand + "[service] in [city]" + "best [specialist] in [city]". Each service page gets its service + city. Doctor pages get "Dr. Name" + "[specialty] in [city]".
Use this map when fixing code (titles, H1, descriptions, content).

## 6. Off-site (brief, a few lines)
For local businesses, remind about Google Business Profile: correct primary category, website link, photos, hours, services, reviews, separate profiles for doctors if allowed, and checking GBP Performance (calls, directions, website clicks) because many local patients never visit the website.

## 7. Output
Keep it simple and scannable:
1. Real data period + totals (one short paragraph; a small line chart of daily clicks/impressions if a chart tool is available)
2. The main problem, in one or two sentences
3. Table of important keywords: keyword | impressions | position | what to do
4. Keyword-to-page map (when code fixes are next)
5. Prioritised next steps (3–5), ending with: upload the project zip for code fixes, if not already shared
Do not promise rankings or traffic numbers. Never invent search volumes; only use the numbers in the file.
